
🌐 CloudFolio – Personal Portfolio Website

📌 About the Project

CloudFolio is a personal portfolio website developed as part of the SkillMe Cloud Internship Program.

This website showcases my profile, technical skills, projects, education, and contact information.

The website is hosted using Amazon Web Services (AWS) S3 Static Website Hosting.

🚀 Technologies Used

- HTML5
- CSS3
- JavaScript
- Amazon Web Services (AWS)

✨ Features

- Modern and clean user interface
- Responsive website design
- Home section
- About Me section
- Technical Skills section
- Projects section
- Education section
- Contact section

☁️ AWS Services Used

- Amazon S3: Static website hosting
- AWS Budgets: Monthly cost monitoring and email alerts
